# モンティホール問題シミュレーション

行動経済学で有名な「モンティホール問題」を実際にコードでシミュレーションするプロジェクトです。

## モンティホール問題とは？

テレビのゲームショーを想定した確率論の問題：

1. 3つのドアがあり、1つのドアの後ろには車（当たり）、残り2つにはヤギ（はずれ）
2. プレイヤーが1つのドアを選ぶ
3. 司会者（モンティ）が残り2つのうち、ヤギがいるドアを1つ開ける
4. プレイヤーは最初の選択を変更できる

**問い**: ドアを変更すべきか？

## 反直感的な答え

- **ドアを変更しない**: 勝率 33.3%
- **ドアを変更する**: 勝率 66.7%

→ **ドアを変更すると勝率が2倍になる！**

## セットアップ

### 1. 仮想環境の作成と有効化

```bash
# 仮想環境の作成（初回のみ）
python3 -m venv venv

# 仮想環境の有効化
source venv/bin/activate  # macOS/Linux
# または
venv\Scripts\activate  # Windows
```

### 2. 依存パッケージのインストール

```bash
# グラフ表示に必要なパッケージをインストール
pip install -r requirements.txt
```

## 使い方

### 基本シミュレーション（コマンドライン）

```bash
# 仮想環境を有効化してから実行
source venv/bin/activate
python monty_hall.py
```

10,000回のシミュレーションを実行し、両方の戦略の勝率を表示します。

### グラフ表示

```bash
# 仮想環境を有効化してから実行
source venv/bin/activate
python monty_hall_viz.py
```

勝率の比較グラフと勝敗の内訳円グラフを表示・保存します。

### 仮想環境の終了

```bash
deactivate
```

## なぜこの結果になるのか？

### 直感的な説明

1. **最初にあたりを選んだ場合（確率 1/3）**
   - ドアを変えると必ず外れる

2. **最初にハズレを選んだ場合（確率 2/3）**
   - モンティがもう一つのハズレを除外してくれる
   - ドアを変えれば必ず当たる

つまり、**最初にハズレを選ぶ確率が 2/3** なので、ドアを変更すれば 2/3 の確率で勝てる！

### 確率的な説明

最初の選択時点：
- 車を選ぶ確率: 1/3
- ヤギを選ぶ確率: 2/3

モンティがヤギのドアを開けた後：
- **変更しない場合**: 最初の1/3の確率のまま
- **変更する場合**: 最初にヤギを選んでいた2/3のケースで車を獲得できる
